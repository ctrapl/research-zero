# 开题素材模板

本文件是 `scripts/export_proposal.py` 的输出契约。脚本按此结构生成 Markdown；块内文字由 plan.json 填充。

## README.md

```markdown
# 开题素材包使用说明

1. 先读 00_开题速览，确认方向是否与导师一致
2. 02 里的每条主线都能回溯到《科研方向地图》的对应章节
3. 所有【待验证】【待填】标记必须处理完再提交
4. 参考文献.bib 导入 Zotero 后先核对年份与作者
```
