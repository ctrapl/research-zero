# Phase 0 澄清脚本

## 为什么要做这一步

用户的第一句话几乎从来不是研究问题：

- "我想做 AI 医疗" —— 这是一个领域名，不是一个问题。里面装着影像诊断、药物发现、电子病历、蛋白结构，检索式完全不同。
- "导师让我找个方向" —— 连学科边界都没给，可能意味着导师有隐含偏好。
- "我对大模型感兴趣" —— 这是技术兴趣，不是研究问题。

直接拿这些去检索，命中动辄几万篇，排序结果会退化成"高被引论文列表"，跟用户的实际处境毫无关系。**澄清 3 分钟，省掉后面全部返工。**

## 四个必问项

用结构化选项提问，不要开放式。开放式的回答通常还是一句模糊的话。

### 1. 阶段与学科背景

> 你现在处于哪个阶段？

- 本科毕设（通常 3–6 个月，要求可完成、不需要创新性突破）
- 硕士开题（1–2 年，要求有一定新意，能发表）
- 博士开题（3–5 年，要求能撑起完整工作）
- 跨领域转行 / 自学（无固定期限，要求先能读懂文献）
- 课程论文 / 竞赛项目（周期短，要求可交付）

同一份"必读清单"，博士需要 40 篇的前沿纵深，本科毕设只需要 15 篇能上手复现的。**这一项直接决定清单规模**，不能省。

### 2. 可用资源

> 你目前手上有什么？（可多选）

- 有可用的数据集 / 队列 / 临床样本
- 有算力（GPU / 集群）
- 有实验设备 / 湿实验条件
- 只有一台笔记本
- 导师已有成熟方向，可以跟着做
- 完全从零开始，没有任何资源

资源决定了哪些"空白"对用户是可做的。一个没有湿实验条件的本科生，指向细胞实验的空白对他毫无意义。

### 3. 时间预算

> 你需要在多长时间内产出结果？

- 3 个月内（毕设中期 / 课程论文）
- 半年
- 1–2 年（硕士）
- 3 年以上（博士）

### 4. 偏好倾向

> 你更想做哪类工作？

- 偏理论：证明、建模、算法性质分析
- 偏工程：系统实现、性能优化、工具链
- 偏应用：落地场景、真实数据、效果验证
- 偏综述：文献梳理、体系构建、benchmark
- 还不确定，想先看看这个领域有什么

## 按阶段调整问法

**本科毕设**：重点问"能不能复现"和"导师有没有基础代码"。这类用户最需要的是"3 个月能做完的最小可行课题"，而不是前沿方向。

**硕士开题**：重点问"导师方向"和"有没有前期积累"。国内硕士开题的现实约束是导师课题，理想方向如果跟导师不搭，基本做不成。要主动问一句"导师希望你往哪个方向靠"。

**博士开题**：重点问"你想在哪个学术共同体里立足"。博士的选题等于选一个未来五年的同行圈子，需要问清楚目标会议/期刊。

**跨领域转行**：重点问"你的原专业是什么"。转行者的最大优势是原领域的视角，最有价值的选题往往是"用 A 领域的方法解决 B 领域的问题"。要主动挖这层。

## 方向确认卡模板

澄清完成后输出这张卡，等用户确认：

```
## 方向确认

**研究问题**：<一句话，必须包含"在什么场景下、解决什么问题、用什么思路">
**范围边界**
  - 做什么：<3 条>
  - 不做什么：<2～3 条，明确排除容易混淆的相邻方向>
**所属子领域**：<细分领域名，不是大领域名>
**关键词簇**
  - 英文：<4～6 组，每组含近义词>
  - 中文：<3～5 个>
**约束条件**：<时间 / 资源 / 导师方向，影响后续清单规模与空白取舍>

确认这个方向对吗？需要调整哪部分？
```

## 追问策略

用户回答含糊时（比如"都行""看情况"），不要接受模糊答案，也不要连珠炮提问。用一句具体的对比把选择逼出来：

- 用户说"都可以" → "那我换个问法：如果只能选一个，你更想三个月后交一份能跑的代码，还是一份讲得清的综述？"
- 用户说"不知道导师要什么" → "导师最近在做什么课题？有没有让你读过哪篇论文？"（从既有线索反推）
- 用户说"想做热点" → "热点有两种：已经挤满人的（比如通用大模型微调），和刚起来还没挤满的（比如某个垂直场景）。你要哪种？"

## 什么时候可以跳过

只有同时满足以下三条才跳过澄清、直接进 Phase 1：

1. 用户已给出明确的研究问题（不是领域名）
2. 已说明阶段和时间预算
3. 已说明约束（资源或导师方向）

三条缺一条就要补问。跳过澄清省下的时间，会在用户看到报告说"这不是我要的"时全部还回去。
