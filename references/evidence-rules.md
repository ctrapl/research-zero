# 证据规则判例

三条规则在 SKILL.md 里只写了一句话，这里给具体判例。遇到拿不准的情况，以本文件的判例为准。

## 规则一：文献条目只能来自脚本

### 反例（全部禁止）

```
❌ "该领域的奠基工作包括 LeCun 1998 年的 LeNet 和 Krizhevsky 2012 年的 AlexNet。"
   —— 这两篇可能确实存在，但没经过本次检索，属于凭记忆作答。
```

```
❌ "另外建议阅读 Goodfellow 的 Deep Learning 一书。"
   —— "另外建议"是绕过检索最常见的口子。要加就必须让脚本搜到。
```

```
❌ 报告里出现 DOI 但脚本返回中无此 DOI。
   —— 这是最严重的一类，用户一查就穿帮，整份报告报废。
```

### 正例

```
✅ 需要补一篇脚本没搜到的经典文献时：
   "脚本以当前检索式未命中 XX（1998）的工作，若需要可自行用标题关键词
    'gradient-based learning applied to document recognition' 核实。"
```

### 边界情况

| 情况 | 处理 |
|---|---|
| 用户点名要某篇论文 | 用标题去脚本里搜一次；搜不到就说明搜不到，不编造元数据 |
| 脚本只返回了标题没有摘要 | 可以用标题做判断，但不要编写内容描述 |
| 两篇文献标题几乎相同（预印本 + 正式版） | 保留正式版，预印本标注"预印本，已被 XX 接收" |

## 规则二：每条文献必须可回溯

渲染器会强制校验，无链接的条目会直接报错。这里是校验口径：

- 有 DOI → 用 `https://doi.org/<doi>`
- 无 DOI 但有 arXiv id → 用 `https://arxiv.org/abs/<id>`
- 两者都无但有 landing page → 用 landing page
- 三者都无 → **剔除该条目**，不要留着占位

同时校验 DOI 格式：必须是 `10.xxxx/...` 形式。`doi.org/10...` 字段出现 `doi:` 前缀、空格、大小写混排都要先规范化。

## 规则三：区分事实与推测

这是三条里最容易被违反的，因为它不像编造 DOI 那样有硬性检测手段。

### 事实的写法

```
✅ "GNN 在分子性质预测上的代表性工作是 MPNN（Duvenaud et al., 2015）与
   D-MPNN（Yang et al., 2019），后者在 12 个 MoleculeNet 任务上报告了
   平均 6% 的误差下降。"
```

判据：每个断言都能指向一篇具体文献的摘要或结论。

### 推测的写法

推测不是不能写，而是必须**带限定词和依据**。

```
✅ "在本次检索的 62 篇记录中，未见将 diffusion model 用于晶格缺陷预测的工作。
   这可能是空白，也可能是检索词未覆盖（diffusion 在材料领域常表述为
   'generative model'）——建议用后一组关键词复核。"
```

```
❌ "diffusion model 在晶格缺陷预测上尚属空白，这是一个很好的切入点。"
   —— 无依据、无范围限定、直接给结论。用户按这个去开题，撞车概率极高。
```

### 三级置信度标注

| 级别 | 判据 | 写法 |
|---|---|---|
| **证据充分** | ≥2 篇独立文献明确支持 | 可直接陈述 |
| **单一来源** | 只有 1 篇文献提到 | "据 X（2024）报告……" |
| **推测** | 无文献支持，基于检索结果的缺席推断 | "本次检索未见……，可能是空白，需进一步核实" |

报告里的"疑似研究空白"段落，**默认全部按第三级写**。V1 没有做空白验证，任何看起来像结论的表述都会误导用户。

## 引用格式

报告内统一用作者-年份行内引用，不用脚注编号（Markdown 里跳转体验差）：

```
（Duvenaud et al., 2015）
（Yang et al., 2019, NeurIPS）
```

中文文献用（作者，年份）。同一作者同年多篇用 2019a / 2019b。

## 自检流程

渲染前按顺序走一遍，任一步失败就回退修改，不要往下走：

1. **链接校验**：`build_report.py` 自动跑，报错就补 DOI 或删条目
2. **"为什么必读"校验**：脚本检查是否为空，但"是否具体"要人判断。把每条理由读一遍，凡是"很重要""值得阅读""经典之作"这类，重写
3. **无主语句扫描**：搜报告里有没有"出现了新方法""取得了突破""受到广泛关注"这类没有主语也没有文献支撑的句子
4. **推测标注扫描**：搜"空白""尚未""首次""无人"，逐条确认是否有依据或限定词
5. **边界声明**：确认报告末尾写了数据源、年份范围、覆盖边界

## 一个自检用的提问

写完报告后问自己一句：

> 如果我是用户的导师，看到这份东西，会问哪三个问题？

通常这三个问题就是报告最薄弱的地方（常见：为什么选这几篇、这个空白你怎么知道没人做、这个方向三年做得完吗）。把它们补进报告的对应位置。
